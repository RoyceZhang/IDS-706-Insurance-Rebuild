# Insurance dataset

The input data is stored in `insurance.csv`. The application expects the following
columns:

- `age`: nonnegative numeric age
- `sex`: nonblank category
- `bmi`: positive numeric body mass index
- `children`: nonnegative integer number of dependents
- `smoker`: `yes` or `no`
- `region`: nonblank category
- `charges`: nonnegative numeric insurance charges
